ML-модели Snapshot и Historical не реализованы, не вызываются и не обучаются. `ModelOutput` принимает по одному результату от каждого слота с schema_version/model_version/source/semantics. Принимаются только заранее откалиброванные месячные вероятности ухода, одинаковые для данной синтетической популяции. Если есть два результата, используется явное сценарное правило: среднее арифметическое, заменяющее базовую вероятность ухода. Это не предположение о статистической независимости моделей. Сырые score, familiarity, anomaly и похожие значения не являются вероятностью и отклоняются. Калибровка и адаптер от реального формата моделей принадлежат команде моделей. В будущем контракт можно версионировать для customer/segment-specific результатов, не меняя существующие модели.

MVP синхронно возвращает отчет; два CPU worker, 128 KiB на запрос, 50 млн верхних candidate evaluations. Для промышленного развертывания следующий шаг — очередь заданий, сохранение replay artifacts, авторизация на уровне gateway. По умолчанию сервис слушает только loopback.
